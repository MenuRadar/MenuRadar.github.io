# MenuRadar

Restaurant Menus, Prices & More.

MenuRadar is a static, SEO-ready restaurant directory foundation targeting the USA, UK, France, Brazil and Australia. The site is structured for expansion into thousands of useful restaurant, city and menu pages.

## Current MVP

- Responsive homepage
- Country landing pages
- Restaurant menu, prices, breakfast, fast-food and hours topic pages
- Search interface
- SEO titles and descriptions
- Canonicals
- robots.txt
- XML sitemap
- About and privacy pages

## Content architecture

Use the pattern `/{country}/{city}/{restaurant}-menu/` for restaurant pages. Each page should contain genuinely useful, verified information such as menu items, prices, categories, hours, locations and FAQs. Avoid thin or duplicated programmatic pages.

## Target markets

USA · UK · France · Brazil · Australia

## Deployment

This repository is compatible with GitHub Pages because it uses plain HTML/CSS and no build step. The canonical URLs should be updated if the production domain changes.
